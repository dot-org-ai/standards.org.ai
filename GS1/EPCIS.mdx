# GS1 EPCIS

**GS1 EPCIS** (*Electronic Product Code Information Services*, 2.0) is the GS1 standard for capturing and sharing supply-chain visibility events. Each event records **what** objects were involved, **when** it happened, **where** it occurred, and **why** (business step and disposition, drawn from the Core Business Vocabulary). Events are designed to be shared across organizational boundaries — evidence a counterparty can consume, not private telemetry.

This page is a **G1 seed**: it registers the standard as a source of record so downstream vocabularies can cite it by stable `$id`. It describes the standard; it does not redefine it. Entity-level pages for the event vocabulary live under [`GS1/EPCIS/`](https://standards.org.ai/GS1/EPCIS/EventType/ObjectEvent) (EventType, BusinessStep, Disposition).
